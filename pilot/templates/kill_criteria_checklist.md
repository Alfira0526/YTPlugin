# 파일럿 중단 기준 (Kill Criteria) 체크리스트

인수인계문서 §5-2 / 게이트 리뷰 신규 정의. 아래 중 **하나라도** 해당하면
현 아키텍처 진행을 중단하고 지정된 대안 절차를 수행한다.

| ID | 기준 | 저촉 시 조치 |
|---|---|---|
| **K1** | 전사 정확도: 샘플 핵심 발화의 절반 이상이 오인식되어 문맥 파악 불가 | STT를 SenseVoice로 교체 재시도 → 그래도 실패 시 프로젝트 방향 재검토 |
| **K2** | 번역 품질: 전사가 정확한데도 한국어 번역이 시청 보조 불가 수준 | MT를 Papago로 교체 재시도 |
| **K3** | 처리 원가: 1시간 영상 처리 원가가 사전 상한(초기 가안 $1/시간, **확인필요**)을 명백히 초과 | 아키텍처 재설계(경량화·캐싱 강화·방식 재검토) |
| **K4** | 지연(방식 a): 자막 표시 지연이 10초를 상습 초과 | 방식 (a) 단독 채택 불가 → (b) 병행 또는 하이브리드 검토 |

## 5. P0 실행 절차 (인수자가 그대로 따라할 수 있는 순서)

### 5-1. 파일럿 ① — 반나절 품질 검증 (최우선)
1. 샘플 #1 영상을 육안 확인 — 중국어 발화 + 유튜브 자동자막 미제공 여부 검증. 부적합 시 대체 샘플 선정
2. 오디오 확보 (로컬 테스트 목적, 배포용 아님)
3. Qwen3-ASR 로컬 구동 → 중국어 전사 결과 육안 평가
4. 전사 결과를 DeepL Free로 번역 → 한국어 품질 육안 평가
5. 결과를 "파일럿 메모"로 기록 (전사 정확도 체감, 번역 자연스러움, 소요 시간, 글자수)

### 5-2. 파일럿 중단 기준 (Kill Criteria) — [게이트 리뷰에서 신규 정의]
아래 중 하나라도 해당하면 현 아키텍처로의 진행을 중단하고 대안 재검토:
- **K1. 전사 정확도**: 샘플의 핵심 발화 절반 이상이 오인식되어 문맥 파악 불가 수준이면 중단 → SenseVoice 등 대체 모델 재시도, 그래도 실패 시 프로젝트 방향 재검토
- **K2. 번역 품질**: 전사가 정확한데도 한국어 번역이 시청 보조 불가 수준이면 중단 → Papago 등 대체 MT 재시도
- **K3. 처리 원가**: 1시간 영상 처리 원가가 사전 상한(파일럿 ③에서 설정, 초기 가안: 영상 1시간당 $1 이내 — 확인필요)을 명백히 초과하면 아키텍처 재설계
- **K4. 지연**: 방식 (a) 검증 시 자막 표시 지연이 10초를 상습 초과하면 (a) 단독 채택 불가 → (b) 병행 또는 하이브리드 검토

### 5-3. 파일럿 ②③ 및 핵심 결정
- 샘플 3~5건으로 확대, 방언 비중·WER 실측
- DeepL vs Papago 비교, 1시간당 글자수·원가 실측 (Papago 무료한도 실측 포함)
- (a)(b) 양 방식 프로토타입 → **오디오 확보 방식 결정서 작성** (P1 진입 조건)

### 5-4. 파일럿 통과 후
- 법률자문 착수: OSP 면책요건, 유튜브 코리아 정책 정합성, (방식 (b) 채택 시) ToS 다운로드 금지 조항 저촉 여부

## 7. 미해결 확인필요 항목 (인수자 필수 인지)

1. 샘플 #1 영상의 콘텐츠 성격 (파일럿 착수 시 육안 확인)
2. Papago 정확한 무료 API 한도 수치
3. 방식 (a) 스트리밍 STT의 실제 품질·지연
4. 방식 (b)의 유튜브 ToS 저촉 여부 (법률자문 대상)
5. OSP 면책요건·유튜브 코리아 정책 정합성 (법률자문 대상)
6. 1시간 영상당 처리 원가 (파일럿 실측 전 미산정, K3 상한 가안 $1은 확정치 아님)
7. 타겟 콘텐츠의 실제 방언 비중
8. Qwen3-ASR의 CPU 단독 구동 가능 여부

## 8. 핵심 리스크 요약 (상세: 개발계획서 v1.1 §6)

- 오디오 확보 방식 미확정 상태로 개발 착수 금지 (P1 진입 조건)

- 원본 콘텐츠(웨이보 재업로드) 저작권: 원칙 친고죄이나 영리목적/상습성 시 비친고죄 — 업로더 리스크이며 개발사 직접 책임 아님. 단 약관에 책임범위 명시 필요
- DeepL 월 50만자는 개인용 규모 — 서비스 확대 결정은 §5 비용 모델 임계점 기준으로만

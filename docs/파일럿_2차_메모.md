# 파일럿 ② 메모 (2차 시도 — 중국어 발화 샘플)

작성일: 2026-07-19
방법: 설치 없는 웹 경로 — TurboScribe
샘플: SEVENTEEN THE8 솔로 웨이보 라이브 (밀라노 디자인위크)
영상: https://www.youtube.com/watch?v=eVPwdqLqlkU (video_id: eVPwdqLqlkU)

> 인수인계문서 §5-1 절차 5 "파일럿 메모" 양식. 두 번째 데이터(중국어 발화 샘플).

---

## 1. 무엇을 했나
- 사용자가 THE8 솔로 웨이보 라이브(중국어 발화) 선정 → TurboScribe로 처리 → 텍스트 산출.
- 산출 텍스트를 육안 확인.

## 2. 핵심 발견
- **이번 샘플은 중국어 발화가 맞음**(THE8이 중국 팬 대상 중국어 진행). 타겟 대표성 확보.
- **TurboScribe가 중국어를 한국어로 자동 "번역"까지 수행** → 산출물이 한국어. 근거:
  - 지명 음차: `미란`(=米兰 밀라노), `커모호`(=科莫湖 코모 호수)
  - 미번역 잔존 중국어: `旋律`(멜로디), `珍惜`(소중히), `小星`, `雜식` 등
- 즉 파일럿 사상 **처음으로 STT+MT end-to-end 결과**를 확보(단, MT는 우리가 고른 DeepL이 아니라 TurboScribe 내장 번역).

## 3. Kill Criteria 대조
- **K1 전사 정확도**: **간접 판정** — 번역문이 전반적으로 일관되고 맥락이 통함 → 전사 자체는 양호로 추정. 단 원문(중국어)을 못 봐서 정밀 측정 불가.
- **K2 번역 품질**: **통과(조건부)** — 뜻이 통하고 시청 보조로 충분. "시청 보조 불가"(kill 기준) 아님.
  - 강점: 전체 서사(밀라노 디자인위크/AD, 가죽 선호, 5월 콘서트·신곡, 팬 행복 기원) 명확히 전달.
  - 약점: 고유명사 오류(미란→밀라노, 커모호→코모 호수, AD라디오→AD 잡지), 미번역 중국어 잔존, 기계번역투 일부 문장.
- K3/K4: 해당 없음(웹 도구).

## 4. 결론 및 조치
- 판정: **개념 검증 긍정.** 중국어 발화 → 한국어 결과가 "쓸 만한 수준"으로 나옴.
- 약점(고유명사·미번역·어색함)은 개발계획서가 이미 대비: **고유명사 용어집** + **Qwen3-ASR/DeepL** 조합으로 개선 대상.
- **다음(선택) — 우리 실제 파이프라인 정밀 검증**:
  1. TurboScribe에서 **번역 끄고 '중국어 원문'** 확보(또는 전사 전용) → K1(전사 정확도) 직접 측정
  2. 그 중국어를 **DeepL(우리 1순위 MT)** 로 번역 → TurboScribe 내장 번역과 품질 비교(K2 정밀)
  3. 최종 정밀 검증은 로컬에서 Qwen3-ASR + DeepL(`docs/RUN_LOCAL.md`)

## 5. 시사점 (제품 관점)
- THE8 같은 **K-pop 그룹의 중국인 멤버가 중국어로 진행하는 웨이보 콘텐츠**가 타겟에 정확히 부합함을 실물로 확인.
- 이 유형은 한국인 팬이 이해 못 하는 진짜 수요 지점 → 제품 가치 유효.

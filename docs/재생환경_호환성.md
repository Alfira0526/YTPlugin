# 재생 환경별 호환성 검증 (2026-07-19)

사용자 제기: "대상 영상이 웹 기반 또는 유튜브 PC 앱으로 출력될 텐데 가능한지 검증할 것."
→ (a) tabCapture + 온디바이스 STT 방식이 각 재생 환경에서 되는지 조사.

## 결론 요약

| 재생 환경 | 우리 방식(크롬 확장 + tabCapture) | 대응 |
|---|---|---|
| **브라우저 탭** (크롬/엣지/크로미엄) | ✅ 완전 동작 | 기본 대상 |
| **설치형 PWA 창** (유튜브 PC "앱") | ✅ 오버레이·콘텐츠 스크립트 동작. 단 팝업 버튼이 안 보임 | **키보드 단축키(commands)로 시작** |
| **공식 네이티브 데스크톱 앱** | — | **2026 현재 존재하지 않음**(구글 미출시) → 대상 아님 |
| **서드파티 래퍼 앱** | ❌ 확장이 못 미침 | 데스크톱 앱(시스템 오디오 루프백 + 오버레이 창) 별도 프로젝트 — MVP 범위 밖 |

## 근거 (조사)

1. **공식 유튜브 PC 앱 없음.** PC에서 "유튜브 앱"은 크롬/엣지로 설치하는 **PWA**(2024 출시). Microsoft Store에도 공식 앱 없음(서드파티 래퍼만 존재).
2. **PWA = 크로미엄 엔진.** 설치형 PWA는 브라우저 엔진 위에서 동작하므로, 유튜브 URL에 매칭된 **콘텐츠 스크립트가 실행**됨 → 오버레이 렌더링 가능.
3. **PWA 창의 제약.** 확장 툴바(action/popup)가 앱 창에는 표시되지 않음 → 팝업으로 tabCapture를 **시작**하기 어려움. 해결: **chrome.commands 키보드 단축키**(앱 창에서도 유효한 확장 호출 경로)로 시작/정지.
4. **온디바이스 STT 실현 가능.** Transformers.js(Whisper) WASM/WebGPU로 브라우저 내 중국어(간체·번체) 인식 가능. WebGPU 시 76MB급 모델 실시간 5~8배속. 계획서 §3-3 "온디바이스 우선" 부합. (실시간 품질·정확도는 모델 크기 트레이드오프 — §3-0 검증 대상 유지.)

## 대응 작업 (진행)

- ✅ **탭·PWA 공통 단축키 트리거**: `chrome.commands`로 실시간 시작/정지(팝업 없이도 앱 창에서 동작).
- ✅ **온디바이스 Whisper STT 클라이언트 스켈레톤**: `SttClient` 인터페이스 구현(Transformers.js 기반). 모델 다운로드가 필요해 이 샌드박스(HF 차단)에선 실행 불가 → 사용자 로컬/실기기 검증 대상.
- 🟡 **서드파티 네이티브 앱 지원**: MVP 범위 밖으로 제안(별도 데스크톱 앱). 범위 확인 요청 → `결정대기_큐.md` Q-5.

## 남은 검증(실기기)
- PWA 창에서 단축키 트리거 → tabCapture 실제 동작 여부(수동).
- 온디바이스 Whisper 중국어 실시간 정확도·지연 실측(로컬/WebGPU).

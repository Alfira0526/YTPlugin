# 파일럿 — 설치 없이 브라우저만으로 (초보자용)

> 대상: 개발 경험이 없는 프로젝트 오너.
> 목적: 카운슬이 정한 "첫 번째로 할 일"(전사·번역 품질 육안 검증)을 **아무것도 설치하지 않고** 웹사이트 3개로 수행.
> 시각 안내서(권장): 세션에서 발행한 Artifact 페이지 참조.

우리 프로그램이 나중에 **자동으로** 할 3가지(① 소리 알아듣기 → ② 중국어 글자로 → ③ 한국어 번역)를,
지금은 이미 나와 있는 무료 웹사이트로 **손수** 해보며 "품질이 쓸 만한가?"만 확인한다.

## 준비물
- 웹브라우저(크롬·엣지·사파리 등)
- 시험할 유튜브 영상 링크 1개 — **중국어 발화 + 자막 미제공** 영상
- 팁: 처음엔 **2~3분짜리 짧은 영상**으로 연습

---

> → **파일 다운로드 없이 링크만 붙여넣는 방식(방법 A)** 을 우선으로 변경.

## 1단계. 영상 속 중국어를 '글자'로 받아쓰기 (약 5분)

> 갱신(2026-07-19): HF 무료 데모(openai/whisper 등)가 500 오류·대기줄로 불안정 →
> 운영형 서비스 **TurboScribe**를 1순위로 변경(유튜브 링크 직접 처리, 자막 없는 영상도 실제 ASR).

### 방법 A — TurboScribe에 링크 붙여넣기 (가장 안정적, 먼저 시도)
1. 유튜브에서 영상 **링크 복사**
2. **TurboScribe** (`turboscribe.ai/l/youtube-transcript-generator`) 접속 — 무료 하루 3개, 영상당 30분까지, Whisper 기반
3. 링크 붙여넣기 → 언어 **중국어(Chinese)** 선택 → **Transcribe**
4. 나온 중국어 글자 전체 복사 (가입 요구 시 이메일로 무료 가입)

### 방법 B — 소리 파일로 받아서 업로드 (백업)
1. 무료 변환 사이트(예: `noadsdl.com/youtube-to-mp3`)에 링크 붙여넣어 **mp3** 받기
   (광고처럼 생긴 버튼 클릭 금지, 설치 금지)
2. 그 mp3를 **TurboScribe에 업로드**, 또는 **Whisper Web** (`huggingface.co/spaces/Xenova/whisper-web`, 브라우저에서 구동되어 서버 오류 없음)에 올려 중국어 글자 획득
   - 우리 1순위 모델로 정밀 확인은 로컬에서: **Qwen3-ASR** (`docs/RUN_LOCAL.md`)

- ⚠️ 둘 다 막히면: 붙잡지 말고 "1단계가 안 됨"을 공유 → 다른 방법 재탐색. 긴 영상은 2~3분 분량으로.
- 참고: TurboScribe/Whisper는 빠른 감별용. 최종 품질은 로컬에서 우리 1순위 Qwen3-ASR로 재확인.

## 2단계. 중국어 → '한국어 번역' (약 3분)
1. **DeepL 번역기(zh→ko)** (`deepl.com/translator/l/zh/ko`) 접속 — 로그인 불필요
2. 중국어 붙여넣기 → 오른쪽에 한국어 자동 표시
- ⚠️ 무료 DeepL은 1회 **1,500자** 한도. 길면 나눠서 붙여넣기.

## 마지막. 눈으로 판단 (Kill Criteria 축약)
- **K1 전사 정확도**: 실제 발화 vs 중국어 받아쓰기가 대체로 맞나? (절반 이상 틀리면 ✗)
- **K2 번역 품질**: 한국어가 자막으로 뜻이 통하나? (어색해도 통하면 OK)

| 결과 | 다음 |
|---|---|
| 둘 다 OK | 좋은 신호 — 이 방향 개발 가능. 결과 공유 → 다음 단계 안내 |
| 하나라도 별로 | 어느 쪽(받아쓰기/번역)이 문제였는지 공유 → 대체 모델·번역기로 재시도 준비 |

### 이 방법과 리포의 `pilot/` 하네스의 관계
- 이 웹 방법 = **품질 확인용 지름길**(설치 없이 즉시).
- `pilot/` 하네스 = 같은 일을 **자동화·측정**(세그먼트 수·글자수·소요시간·원가)하는 코드. 로컬/GPU 환경이 준비되면 `docs/RUN_LOCAL.md`로 실행.
- 둘 다 같은 질문("전사·번역 품질이 쓸 만한가")에 답하며, 웹 방법으로 먼저 감을 잡고 하네스로 정밀 측정하는 순서가 자연스럽다.

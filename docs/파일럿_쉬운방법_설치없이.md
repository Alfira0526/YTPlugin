# 파일럿 — 설치 없이 브라우저만으로 (초보자용)

> 대상: 개발 경험이 없는 프로젝트 오너.
> 목적: 카운슬이 정한 "첫 번째로 할 일"(전사·번역 품질 육안 검증)을 **아무것도 설치하지 않고** 웹사이트 3개로 수행.
> 시각 안내서(권장): 세션에서 발행한 Artifact 페이지 참조.

우리 프로그램이 나중에 **자동으로** 할 3가지(① 소리 알아듣기 → ② 중국어 글자로 → ③ 한국어 번역)를,
지금은 이미 나와 있는 무료 웹사이트로 **손수** 해보며 "품질이 쓸 만한가?"만 확인한다.

## 준비물
- 웹브라우저(크롬·엣지·사파리 등)
- 시험할 유튜브 영상 링크 1개 — **중국어 발화 + 자막 미제공** 영상
- 팁: 처음엔 **2~3분짜리 짧은 영상**으로 연습

---

## 1단계. 영상의 '소리'를 파일로 저장 (약 3분)
1. 유튜브에서 영상 **링크 복사**
2. **cobalt.tools** 접속 → 링크 붙여넣기 → 형식 **오디오(mp3)** 선택 → 다운로드
3. '다운로드' 폴더에 `.mp3` 생성되면 완료
- ⚠️ cobalt가 막히면(유튜브가 가끔 차단): "youtube to mp3" 검색으로 다른 무료 변환 사이트 사용, 또는 더 짧은 영상. **개인 확인용으로만** 잠깐 사용.

## 2단계. 소리 → '중국어 글자' (약 5분)
1. **Qwen3-ASR 데모** (`huggingface.co/spaces/Qwen/Qwen3-ASR-Demo`) 접속 — 우리 1순위 STT 모델
2. `.mp3` 업로드 → **Submit**
3. 나온 중국어 글자(Result) 전체 복사
- 백업: **SenseVoice 데모** (`huggingface.co/spaces/FunAudioLLM/SenseVoice`) — 2순위 모델, 같은 방식. 긴 영상은 2~3분 분량으로.

## 3단계. 중국어 → '한국어 번역' (약 3분)
1. **DeepL 번역기(zh→ko)** (`deepl.com/translator/l/zh/ko`) 접속 — 로그인 불필요
2. 중국어 붙여넣기 → 오른쪽에 한국어 자동 표시
- ⚠️ 무료 DeepL은 1회 **1,500자** 한도. 길면 나눠서 붙여넣기.

## 마지막. 눈으로 판단 (Kill Criteria 축약)
- **K1 전사 정확도**: 실제 발화 vs 중국어 받아쓰기가 대체로 맞나? (절반 이상 틀리면 ✗)
- **K2 번역 품질**: 한국어가 자막으로 뜻이 통하나? (어색해도 통하면 OK)

| 결과 | 다음 |
|---|---|
| 둘 다 OK | 좋은 신호 — 이 방향 개발 가능. 결과 공유 → 다음 단계 안내 |
| 하나라도 별로 | 어느 쪽(받아쓰기/번역)이 문제였는지 공유 → 대체 모델·번역기로 재시도 준비 |

---

### 이 방법과 리포의 `pilot/` 하네스의 관계
- 이 웹 방법 = **품질 확인용 지름길**(설치 없이 즉시).
- `pilot/` 하네스 = 같은 일을 **자동화·측정**(세그먼트 수·글자수·소요시간·원가)하는 코드. 로컬/GPU 환경이 준비되면 `docs/RUN_LOCAL.md`로 실행.
- 둘 다 같은 질문("전사·번역 품질이 쓸 만한가")에 답하며, 웹 방법으로 먼저 감을 잡고 하네스로 정밀 측정하는 순서가 자연스럽다.

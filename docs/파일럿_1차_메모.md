# 파일럿 ① 메모 (1차 시도)

작성일: 2026-07-19
방법: 설치 없는 웹 경로 — TurboScribe(전사) → (번역 예정 DeepL)
샘플: SEVENTEEN THE8·VERNON 웨이보 라이브 (유튜브 재업로드) — 사용자 제공, TurboScribe로 전사

> 인수인계문서 §5-1 절차 5 "파일럿 메모" 양식. 실제 첫 데이터 기록.

---

## 1. 무엇을 했나
- TurboScribe에 영상 투입 → 텍스트 산출(자동). cobalt·HF 데모 실패 후 TurboScribe로 성공.
- 산출 텍스트를 육안 확인.

## 2. 핵심 발견 (중요)
- **전사된 내용이 대부분 한국어였음.** 중국어는 소수 구절만 섞임(예: `天使`, `别啥都骂 你们也就是看他看不懂`, `刚才有拍…`, `Boys and Girls 会有Change吗`).
- 원인: 이 클립의 발화자(세븐틴 THE8·VERNON)가 실제로 **주로 한국어로 말함**. 세븐틴은 한국 그룹.
- 함의: 발화가 한국어면 한국인 사용자는 이미 이해 → **중국어→한국어 번역기의 가치가 거의 없음**. 이 샘플은 타겟 대표성이 없음.

## 3. Kill Criteria 대조
- **K1 전사 정확도**: TurboScribe(Whisper 기반) 전사는 대화 맥락이 자연스럽게 읽힘 → **전사 도구 자체는 양호**(단 언어가 한국어라 우리 목적과 불일치).
- **K2 번역 품질**: **미검증** — 번역할 중국어 분량이 거의 없어 이번 샘플로는 zh→ko 번역 품질을 판정 불가.
- K3/K4: 해당 없음(웹 도구, 원가·지연 측정 대상 아님).

## 4. 결론 및 조치
- 판정: **[조건부] — 샘플 교체 후 재실행.**
- 타겟 재확인(사용자): **한국 아이돌 웨이보 콘텐츠가 맞되, 발화자가 중국인(중국어로 말하는) 클립**이어야 함. 예: 세븐틴의 중국 멤버 THE8이 중국어로 진행하는 웨이보 라이브/솔로 콘텐츠.
- 개발계획 핵심 전제(중국어 발화 → 한국어 번역)는 **유효**. 도구 경로(TurboScribe→DeepL)도 **검증됨**.
- **다음: 중국어 발화 샘플로 파일럿 ① 재실행** → 이번엔 전사가 중국어로 나와야 정상 → DeepL로 한국어 번역 품질(K2) 판정.

## 5. 좋은 샘플 판별 기준 (재실행용)
- 재생 후 10~20초 들어보아 **중국어로 들리면 적합**(한국어면 부적합).
- 우선순위: 중국 멤버가 **중국 팬 대상으로 중국어로 말하는** 라이브·팬미팅·인터뷰.
- 유튜브 자동자막이 **없는** 영상이면 타겟 상황과 더 일치(무자막 전제).
